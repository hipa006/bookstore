# 📚 Bookie - Plateforme de Librairie en Ligne

**Bookie** est une application web dynamique développée avec PHP, MySQL et un assistant virtuel intelligent (Chatbot Python Flask). La plateforme permet aux utilisateurs d'explorer un catalogue de livres, de filtrer par catégorie et de passer une commande générant un code de retrait unique pour récupérer le livre directement en magasin.

---

## ✨ Fonctionnalités Principales

- **Catalogue Interactif :** Parcourez une sélection de livres avec filtrage par catégorie.
- **Système de Réservation avec Code de Retrait :** Validation de commande générant un code unique à présenter en boutique pour le paiement et le retrait.
- **Panier d'Achat Réactif :** Ajout de produits et gestion des quantités directement dans le panier.
- **Chatbot Intelligent :** Assistant virtuel intégré (développé en Python/Flask) pour répondre aux questions des clients en français.
- **Panneau d'Administration :** Gestion des livres, catégories et commandes.

---

## 🛠️ Technologies Utilisées

- **Front-end :** HTML5, CSS3, JavaScript
- **Back-end :** PHP (PDO)
- **Base de données :** MySQL
- **Assistant IA :** Python (Framework Flask)
- **Environnement :** XAMPP (Apache & MySQL)
